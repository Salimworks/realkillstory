CrimeTales Privacy Policy

Applies to the CrimeTales uploader used by @realkillstory. Last updated 22 November 2026.

What the app is

CrimeTales is a private tool run by the owner of the @realkillstory channels. It uploads short true-crime videos made by the owner to the owner's own YouTube channel, Instagram account, Facebook Page and TikTok account. It has no other users and offers no sign-up.

What data it uses

  • The access tokens Google and Meta issue when the owner signs in, stored only on the owner's computer.
  • The owner's channel and account IDs and names, used to post to the right place.
  • The video files, titles, descriptions and tags the owner publishes.

It does not read viewers' data, comments, messages or contacts, and it does not collect data from anyone other than the owner.

How Google user data is used

The app uses the YouTube Data API only to upload videos to the owner's channel and to read the channel's name and ID. It does not share, sell or transfer Google user data to anyone, and does not use it for advertising. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Tokens are kept in a local file on the owner's computer and are never uploaded anywhere else. Access can be removed at any time at myaccount.google.com/permissions (Google), in Facebook's Business Integrations settings (Meta), or under Settings and privacy, Security, Apps and services in the TikTok app, after which the stored tokens stop working and are deleted.

How TikTok user data is used

The app uses TikTok's Login Kit and Content Posting API only to read the owner's display name and username and to post the owner's own videos with their captions. It does not read followers, comments, messages or other users' data, and does not share or sell TikTok data.

Terms of use

The app is for the owner's personal use only and is not offered to anyone else. Videos posted with it follow the terms and community guidelines of each platform.

Contact

Questions about this policy: send a message to @realkillstory on Instagram.
